Welcome, applicant.

Before your first deployment, DoJ/HR requires every pilot to complete a short registration interview.
This client records your answers and forwards them to your assigned administrator.

### How to register

1. **[Download the registration client](../../releases/latest/download/Pilot_Registration.exe)** (Windows, ~110 MB).
2. Run `Pilot_Registration.exe`. It opens full screen.
3. Turn your **sound on**, and set aside about fifteen minutes somewhere quiet.
4. Answer every question honestly.
5. When the interview is complete, send your pilot record file to your administrator.

### "Windows protected your PC"

The registration client is Union software and is not signed by a Cradle-era certificate authority.
If Windows shows a blue warning screen, select **More info**, then **Run anyway**.

### Support

If the client stops responding, press **Alt + F4**.
